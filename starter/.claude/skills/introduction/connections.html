    ב-VS Code: Reload Window
    את ההתחברות עושים רק אתם. אף אדם אחר ואף תוכנה לא יכולים להתחבר במקומכם.

    כדי לטעון מחדש את החלון לוחצים Ctrl Shift P, ומקלידים Reload Window.

    Toffu

    ל-Toffu מחברים חיבור נפרד לכל לקוח

    לכל לקוח יש ב-Toffu סביבת עבודה משלו, ולכן לכל לקוח יש חיבור משלו.

    1. /setup-vault נותן לכם טבלה: שם וכתובת לכל לקוח
    2. בעמוד החיבורים לוחצים Add custom connector
    3. מדביקים את השם ואת הכתובת מהטבלה
    4. מתחברים ל-Toffu כשהדפדפן מבקש
