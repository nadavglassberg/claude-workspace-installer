מקימים את ה-vault: ארבעה צעדים, ואת השאר Claude בונה

ההתקנה כבר שמה על המחשב את כל מה שצריך. עכשיו פותחים את Obsidian על התיקייה הנכונה, מוודאים ש-Claude פעיל, ומריצים סקיל אחד.

בסוף המצגת תדעו:
  1. Obsidianפותחים אותו על התיקייה של ה-vault
  2. Claude Codeמוודאים שהוא פעיל, ופותחים שיחה
  3. החיבוריםארבעה כלים, פעם אחת
  4. /setup-vaultמריצים, ועונים על שאלה אחת
לפני שמתחילים

מתקינים Wispr Flow, כדי לדבר עם Claude במקום להקליד

Wispr Flow היא תוכנת הכתבה. מחזיקים מקש, מדברים, והיא מקלידה את מה שאמרתם בכל חלון, כולל השיחה עם Claude.

  1. פותחים את הקישור, ונרשמים דרכו
  2. מורידים את התוכנה, ומתקינים אותה
  3. חוזרים לכאן, וממשיכים לצעד 1
פתיחת Wispr Flow

למה זה שווה את הדקה

מדברים מהר יותר ממה שמקלידים, ולכן מסבירים ל-Claude יותר. ככל שההסבר מלא יותר, התוצאה מדויקת יותר.

זה קישור הפניה של נדב. אפשר גם לדלג על הצעד הזה, ולהקליד כרגיל.

צעד 1 מתוך 4: Obsidian

פותחים את Obsidian, ובוחרים את התיקייה של ה-vault

  1. פותחים את Obsidian מתפריט התחל
  2. בשורה Open folder as vault לוחצים Open
  3. מדביקים את הנתיב שמופיע כאן בשורת הכתובת שבראש החלון, ולוחצים Enter
  4. לוחצים Select Folder
הנתיב של ה-vault שלכם, במחשב הזה

ה-vault ריק כרגע, וזה בסדר. Claude ימלא אותו בצעד האחרון, ותראו את הדפים מופיעים ב-Obsidian בזמן אמת.

צעד 2 מתוך 4: Claude Code

מוודאים ש-Claude Code פעיל ב-VS Code

  1. עוברים ל-VS Code. הוא נפתח בסוף ההתקנה, על התיקייה claude-workspace
  2. לוחצים Ctrl Shift X. נפתחת רשימת התוספים
  3. מחפשים ברשימה את Claude Code, ולוחצים עליו
  4. מופיע כפתור Disable? התוסף פעיל, והכל תקין. מופיע Enable? לוחצים עליו
התוסף כבוי, ואי אפשר להפעיל אותו?

התיקייה נפתחה במצב מוגבל. לוחצים על Restricted Mode בפינה השמאלית התחתונה, ואז על Trust.

באותה רשימה נמצא גם Claude Code RTL Support. הוא מיישר את העברית לימין, וגם הוא צריך להיות פעיל.

צעד 2 מתוך 4: Claude Code

פותחים שיחה חדשה עם Claude

  1. לוחצים על הסמל של Claude, כוכב כתום, בסרגל שבצד החלון או בפינה העליונה שלו
  2. בפעם הראשונה Claude מבקש להתחבר. מתחברים עם החשבון שבו הצטרפתם לצוות. לא צריך לרכוש מנוי: ההזמנה לצוות מגיעה מאיתנו במייל
  3. לשיחה חדשה ונקייה לוחצים על כפתור השיחה החדשה, בראש חלון השיחה
לא מוצאים את הסמל?

לוחצים Ctrl Shift P, מקלידים Claude Code: Open in New Tab, ולוחצים Enter.

לשיחה חדשה, באותה דרך: Claude Code: New Conversation

כל משימה גדולה מתחילה בשיחה חדשה. שום דבר לא הולך לאיבוד: מה שחשוב כתוב ב-vault.
צעד 3 מתוך 4: החיבורים

מחברים את ארבעת הכלים, פעם אחת

  1. פותחים את עמוד החיבורים באתר של Claude
  2. ליד כל אחד מהארבעה לוחצים Connect: Notion, Slack, Gmail ו-Google Drive
  3. מתחברים עם חשבון העבודה, ומאשרים את הגישה
  4. חוזרים ל-VS Code, לוחצים Ctrl Shift P, ובוחרים Developer: Reload Window
פתיחת עמוד החיבורים
בלי החיבורים Claude בונה vault ריק. איתם הוא ממלא אותו בלקוחות, במשימות ובצוות שלכם.

שכחתם אחד? לא נורא. /setup-vault בודק מה מחובר, ואומר בדיוק מה חסר.
