מה משמש כאן

בסביבה הזו כבר פתחתם שתי דלתות, ויש עוד אחת שעובדת מאחורי הקלעים

בהתקנה של הסביבה פתחתם דלת, אולי בלי לשים לב.

ההתקנה ביקשה מכם להדביק שורה ב-PowerShell. באיזו דלת השתמשתם?

נכון.

התשובה: CLI.

שורה שמדביקים בחלון טרמינל ומריצים היא CLI. ב-Windows החלון הזה הוא PowerShell.

CLI

שורת ההתקנה וההיסטוריה של ה-vault

Claude מריץ פקודות במחשב שלכם, ומבקש אישור לפני כל פקודה.

MCP

חמשת החיבורים

Notion, Slack, Gmail, Google Drive ו-Toffu.

API: אתם לא נוגעים בו. החיבורים משתמשים בו מאחורי הקלעים.
סקיל מול חיבור

חיבור נותן ל-Claude גישה, וסקיל אומר לו איך לעשות את העבודה

חיבור

נותן גישה לכלי

למשל ל-Notion. בלי סקיל יש ל-Claude גישה, אבל הוא מאלתר בכל פעם.

סקיל

אומר איך לעשות עבודה

הוראות לעבודה אחת, למשל איך לפתוח משימה. בלי חיבור אין לסקיל לאן לכתוב.

/add-task הוא סקיל, והוא משתמש בחיבור ל-Notion
סיכום

מה חשוב לזכור

שלוש דלתותAPI בשביל תוכנות ומפתחים, CLI להקלדת פקודות במחשב, ו-MCP לחיבורים שנבנו בשביל AI.
ההבדליםאם יש חיבור, משתמשים בו. קבצים ותוכנות במחשב שלכם הם CLI עם Claude. משהו מותאם בלי חיבור הוא עבודה של מפתח, עם API.
מה משמש כאןשורת ההתקנה היא CLI. החיבורים ל-Notion, Slack, Gmail, Google Drive ול-Toffu הם MCP.
סקיל מול חיבורחיבור נותן ל-Claude גישה לכלי, וסקיל אומר לו איך לעשות את העבודה. הם עובדים ביחד.
